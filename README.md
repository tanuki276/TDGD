# VILSSHUMI
日本語の架空ウイルス創作・仮想世界シミュレーション。依存ライブラリ不要の静的Webアプリ。

## 実行
`python3 -m http.server 8080` で起動。`npm test` でモデルを検証。
VercelではFramework PresetをOther、Output Directoryを `.` に設定。

## 機能
名前・設定・形態・色・架空特性の編集、ランダム創作、ブラウザ内標本保存、6地域の世界地図、365日進行、一時停止、速度変更、日送り、対応策、経済・社会・適応の推移、イベントログ。

## モデル
現実の病原体、感染経路、疫学データは使用しない。夢・光・時間に作用する架空現象。地域ごとの影響割合は共鳴力、架空の地域間距離、世界の適応で変動。経済と安定度は影響割合・干渉・政策に遅れて追随する。結果は決定的で、現実予測ではない。外観と自由記述は計算に影響しない。履歴は直近120日。保存対象は標本のみで進行状態は保存しない。
