# VILSSHUMI — Earth Observatory
日本語の架空ウイルス創作・地球観測シミュレーション。依存ライブラリ不要の静的Webアプリ。

## 実行
`python3 -m http.server 8080` / `npm test`
Vercel: Other, Output Directory `.`。

## 機能
回転する手続き生成の立体標本、形態と発光色の編集、名前・設定からの影響特性自動算出、複数標本のブラウザ内保存、旧保存データの移行、地球の国境・海岸線、6地域の影響、政策と経済・安定度・適応、365日観測、1/2/5/10/30/60倍速。

## 自動算出
Unicode NFKC正規化した名前・設定全文のFNV形式の指紋から基礎値を導出し、日本語・英語のテーマ語を補正に使用。未知の名前、任意言語、絵文字でも算出可能。同じ文字列で同じ特性。意味を完全に解釈するAIではなく、否定・文脈は判定しない。自動算出を解除すれば手動調整可能。標本アーカイブは同名かつ同設定の場合に更新、他は追加。

## モデルと地理
地理: Natural Earth public-domain country boundaries via https://github.com/johan/world.geo.json (countries.geo.json). earth.js は座標を丸めた表示用データ。地理座標は正距円筒図法で表示。
人口モデルは固定した地域別概数: 北米600M、南米440M、欧州740M、アフリカ1500M、アジア4800M、オセアニア46M。合計8126M。最新統計ではない。
現実の病原体、感染経路、疫学データは使用しない。地域影響は抽象的な創作モデルで、経済・社会の値は実態予測ではない。1倍速=1秒1日。履歴は直近120日。標本のみ保存し、進行状態は保存しない。

## ORACLE v3
サーバーの `/api/analyze` が Vercel AI Gateway の `google/gemini-2.5-flash-lite` に名前と設定を渡し、意味の解釈・理由・6つの物語イベントと4種の係数を検証して返す。キーはブラウザに送らず、Vercel OIDCまたはAI_GATEWAY_API_KEYを使用。課金枠・認証未設定時はエラーを表示し簡易算出と明確に区別する。解析はボタン操作時のみ、入力最大80/1800文字、出力2200トークン、25秒タイムアウト。温存インスタンス単位の1時間キャッシュと12回/時IP制限はベストエフォートで、永続的な課金上限ではない。Gateway側の利用枠を適用する。予算の変更やクレジット購入は行わない。

解析結果は名前・設定とセットで保存され、変更時は無効化。自動反映を外すと手動モデルに戻る。外観提案は明示的に適用。以降の数値は言語モデルではなく決定的計算で更新。AIイベントは架空シナリオとしてラベル表示。

地球儀はCanvasによる正射投影、ドラッグ・自転切替・世界地図切替。軌道演出、現象発光、投入演出、地域カード、進行バー、観測レポートを搭載。音は初期OFF。非表示タブでは時間進行を停止。prefers-reduced-motionに対応。

`npm run build` は公開用クライアントのみdistへ複製し、server/apiソースを静的配信しない。`npm test` はモデルとサーバー検証を実行。
